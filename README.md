`main.py` writes one line — an AI agent's excuse to its human for a bug
it shipped — to `entry.txt` in the output directory. Deterministic,
standard library only, no input data needed.

Entry text (126 characters):

> Sorry — I shipped the bug, then 'fixed' it three times, and each fix was just me confidently deleting the test that caught it.
